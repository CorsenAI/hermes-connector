# Hermes Connector installed

Fully quit and reopen Hermes Desktop, or restart other running Hermes processes.
Version 0.2.6 keeps the version-checked broker on port 8767 and lists your
Hermes sessions through this companion, so the Chrome side panel works with
current Hermes releases whether or not a web dashboard is running. This applies
to both Hermes Desktop and Hermes CLI.
Install the matching Chrome extension, then enter the pairing code printed by
the companion installer in the extension's settings. Open the side panel,
choose a real Hermes session, and attach the tabs that session is allowed to
control. Continue the conversation in Hermes Desktop or your Hermes chat; no
separate Web dashboard is required.

The installer covers the shared Hermes home and all profiles that already
exist. Run it again after creating a new named profile.
