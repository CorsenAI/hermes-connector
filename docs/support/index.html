Chrome Web Store transition: public 0.2.0 · candidate/reviewer 0.2.2

Choose the matching extension and companion

Check the extension version first: open chrome://extensions, find Hermes Connector, and read its version. Install only the companion from the same row.

Do not mix versions. Extension 0.2.0 must use companion 0.2.0. Extension 0.2.2 must use companion 0.2.2. Companion 0.2.1 is not part of either Store transition pair.

Install the matching companion

  1. Use the compatibility table above to download the companion that exactly matches the version shown by Chrome, then extract it.
  2. On Windows with companion 0.2.0, open PowerShell in the extracted folder and run .\install.ps1. Companion 0.2.2 also lets you double-click Install Hermes Connector.cmd. On macOS/Linux, run ./install.sh.
  3. Restart any running Hermes dashboard, gateway, or chat process. Re-run the installer after creating a new named Hermes profile.
  4. Open the Chrome side panel, paste the private pairing code printed locally, select a Hermes session, and attach only the tabs it may control.

During the 0.2.2 Store review

Chrome updates the Web Store extension automatically after Google publishes an approved update, but Chrome cannot update the separately installed local companion.

  • If Chrome still shows 0.2.0: keep or reinstall companion 0.2.0. Do not install companion 0.2.2 early.
  • When Chrome shows 0.2.2: install companion 0.2.2, then restart every running Hermes dashboard, gateway, and chat process.
  • If the wrong companion was installed: run the installer from the correct row above and restart Hermes. Recheck both version numbers before troubleshooting anything else.

The default local broker is 127.0.0.1:8765 for pair 0.2.0 and 127.0.0.1:8766 for pair 0.2.2.

Troubleshooting

  • Companion offline: first confirm that the extension and companion versions match. Then confirm Hermes restarted and the matching default port is available: 8765 for 0.2.0 or 8766 for 0.2.2.
  • Pairing rejected: rerun the matching companion installer to display the local pairing code, then save that code again in the extension.
  • Action refused: select the exact Hermes session and attach a permitted web tab. Restricted Chrome pages cannot be controlled.
  • Debugging banner: disable Trusted input unless native input or dialog handling is needed.
