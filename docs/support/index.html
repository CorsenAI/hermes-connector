Open chrome://extensions, find Hermes Connector, and read the installed version before downloading a companion. Use only the companion from the same row.

Do not mix versions. A newer companion is not a compatible upgrade by itself. Update the extension first, then install the companion with exactly the same version.

Install and pair the matching version

  1. Install Hermes Connector from the Chrome Web Store and read its version in chrome://extensions.
  2. Download and extract the companion from the matching row above.
  3. On Windows, double-click Install Hermes Connector.cmd, or run .\install.ps1 in PowerShell. On macOS/Linux, run ./install.sh.
  4. Restart every running Hermes dashboard, gateway, and chat process. Re-run the installer after creating a new named Hermes profile.
  5. Open the Chrome side panel, paste the private pairing code printed locally, choose the exact Hermes profile/session, and attach only the tabs it may control.

Upgrading to 0.2.3

  1. Chrome normally updates the Store extension automatically. Confirm the installed version in chrome://extensions.
  2. When Chrome shows 0.2.3, install companion 0.2.3. If Chrome temporarily still shows 0.2.2, keep companion 0.2.2 until the extension updates.
  3. Restart every running Hermes process. Default installations migrate from legacy port 8765 to protocol 4 on port 8766.
  4. If you deliberately configured a custom bridge port, reboot the computer once after installation, or safely stop only the known legacy broker process before restarting Hermes.

Your pairing code is normally preserved by the companion upgrade. If pairing is rejected, rerun the matching installer and save the locally displayed code again.

Version 0.2.0 disk-growth recovery

Version 0.2.0 could repeatedly write extension state and enlarge Chrome's LevelDB journal. Version 0.2.1 and later stop the known repeated writes, but Chrome may not immediately reclaim disk space that was already consumed.

  1. Upgrade the extension and companion to the latest matching version shown by Chrome.
  2. Close every Chrome window completely, wait for Chrome processes to exit, and reopen Chrome.
  3. If the extension's storage remains abnormally large, remove and reinstall Hermes Connector from the Chrome Web Store. This clears this extension's local settings.
  4. Paste the pairing code again, name the Chrome profile if required, reselect the Hermes session, and reattach the permitted tabs.

Do not manually delete arbitrary files from the Chrome profile. Removing the extension clears its settings, including pairing and tab/session bindings, but does not remove the separately installed Hermes companion.

Troubleshooting

  • Companion offline: verify that extension and companion versions match, restart Hermes, and confirm that the matching default port is available: 8766 for 0.2.1/0.2.2/0.2.3 or 8765 for 0.2.0.
  • Pairing rejected: rerun the matching companion installer to display the current local pairing code, then save it again in the extension.
  • Action refused: select the exact Hermes session and attach a permitted normal web tab. Chrome internal pages and other restricted pages cannot be controlled.
  • Wrong tab or stale session: detach the tab, select the intended session, and attach it again. The connector fails closed instead of silently using another active tab.
  • Chrome debugging banner: disable Trusted input unless native input events or dialog handling are required.
