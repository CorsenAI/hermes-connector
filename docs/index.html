Local-first security model

Authority remains visible and revocable.

  • No Corsen AI relay, analytics, advertising, tracking, or telemetry.
  • Loopback-only transport on 127.0.0.1:8766.
  • Role-bound mutual HMAC authentication without transmitting the pairing secret.
  • Explicit tab attachment and fail-closed routing when no valid target exists.
  • Sensitive form fields and URL secrets are redacted from browser snapshots.
  • Trusted input is disabled by default and shows Chrome's debugger banner when enabled.

Common questions

Hermes Connector FAQ

Does Chrome update Hermes Connector automatically?

Chrome updates the Web Store extension. It cannot update the separately installed local companion, so install the matching companion manually after an extension version change and restart Hermes.

Can Hermes control every tab after installation?

No. A Hermes session can read or control only normal web tabs you explicitly attach to that exact session. The connector refuses actions when no authorized target exists.

Does Corsen AI receive browsing data?

No Corsen AI relay or telemetry endpoint is used. Page content goes to the user's local Hermes installation. A remote model provider receives content only when the user configured Hermes to use that provider.

What happens when I enable Trusted input?

The extension uses Chrome's debugger transport for reliable native input events and dialog handling in the selected attached tab. Chrome displays its debugging banner while it is attached.

Is this an official Nous Research extension?

No. Hermes Connector is an unofficial community project by Corsen AI and is not affiliated with or endorsed by Nous Research or Google.
