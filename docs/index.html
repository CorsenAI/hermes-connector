Your signed-in browser

Useful browser actions

Navigate, inspect, read, click, type, scroll, take requested screenshots, use keys, select options, drag, search, and manage scoped tabs.

◫

One side panel

In web-dashboard mode, the dashboard stays inside the Chrome side panel. In 0.2.4 Desktop mode, the panel shows session and tab controls while the existing Hermes Desktop window keeps the conversation—there is no duplicate chat to synchronize.

Local by design

Your tab data does not pass through a Corsen AI relay.

  • The companion binds to loopback on your computer.
  • The extension and companion use mutual HMAC authentication.
  • Passwords, one-time codes, and payment-field values are redacted from accessibility snapshots.
  • Tabs stay inaccessible until you attach them to a Hermes session.

Know where your data goes

Selected page content is sent to your local Hermes installation so it can perform the requested action. If you configured Hermes to use a remote model or service, Hermes may then send content to that chosen provider under its terms.

Corsen AI does not operate an analytics service, account system, telemetry endpoint, or content relay for the extension.

Read the complete privacy policy or inspect the public source code.

Questions, answered

Hermes Connector FAQ

For step-by-step installation and troubleshooting, use the setup and support guide.

What is Hermes Connector?

Hermes Connector is an unofficial Chrome browser extension by Corsen AI. It connects exact local Hermes Agent profiles and sessions to the Chrome tabs selected by the user.

Do I need to install anything besides the Chrome extension?

Yes. Hermes must already run locally, and the matching Hermes Connector companion must be installed once. The companion contains the local broker that securely connects Hermes and Chrome.

Can Hermes access every open tab?

No. Hermes can read or control only tabs you explicitly attach to the selected session. Restricted Chrome pages cannot be controlled.

Does it work with websites where I am already signed in?

Yes. Hermes Connector uses your selected, normal Chrome profile and its existing site sessions. It does not read website cookies or browser login storage directly.

Does Chrome update Hermes Connector automatically?

Chrome updates the Web Store extension automatically. It cannot update the separately installed local companion. After any extension version change, verify the version shown by Chrome, install the companion with exactly the same version, and fully restart Hermes Desktop or the running Hermes services.

Is this an official Nous Research extension?

No. Hermes Connector is an unofficial community project by Corsen AI and is not affiliated with or endorsed by Nous Research or Google.
