What is the companion?

It is the small Hermes Connector plugin installed inside your existing Hermes setup. It includes the local broker automatically; it is not another app or account. Communication stays on this PC through 127.0.0.1, and Corsen AI operates no relay or telemetry service.

On macOS or Linux, run ./install.sh instead. Keep the pairing code private. Run the installer again after creating a new named Hermes profile.
