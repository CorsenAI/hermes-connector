What is the companion?

It is the small Hermes Connector plugin installed inside your existing Hermes setup. It includes the local broker automatically; it is not another app or account. The Connector transport between Chrome and Hermes stays on this PC through 127.0.0.1, and Corsen AI operates no relay or telemetry service. Hermes may still send prompts and attached content to the model provider you configure.

On macOS or Linux, run ./install.sh instead. Keep the pairing code private. Run the installer again after creating a new named Hermes profile.

Installation steps
Download companion Setup help
Choose the Hermes project/session that should own browser tabs.
Attached content may be sent to the model provider configured in Hermes.

Only tabs you explicitly attach can be read or controlled. Switching Chrome tabs does not silently move Hermes: the target shown here stays selected until you press “Use current”.

The Connector sends the attached tab URL, visible content and requested screenshots locally to Hermes. Hermes may then send them to the model provider you configured. The Tabs menu reads tab titles locally so you can choose or revoke access.

Start Hermes and open its dashboard (hermes dashboard), then this panel shows it here. If your dashboard runs on a different port, set its address with the ⚙ button.
